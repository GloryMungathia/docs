The admin dashboard gives you full control over all platform users. You can onboard new users, update their details, and archive accounts when needed. Every user on the Pamodzi platform — regardless of role — is created and managed from this section.

## Onboarding a new user

<Steps>
  <Step title="Go to User Management">
    Select **User Management** from the dashboard sidebar.
  </Step>
  <Step title="Click Onboard User">
    This opens the user creation form.
  </Step>
  <Step title="Select the user role">
    Choose from **Farmer**, **Cooperative Agent**, **Wholesale Buyer**, or **Administrator**. The form fields update based on the role you select.
  </Step>
  <Step title="Fill in the required details">
    Enter the user's name, phone number, NRC number, and any role-specific fields (see the table below for a full breakdown).
  </Step>
  <Step title="Submit">
    Click Submit to create the account. The user receives a confirmation and their login credentials via SMS or email.
  </Step>
</Steps>

## User roles and required fields

Each role requires a different set of information at onboarding.

| Role | Required fields |
|---|---|
| **Farmer** | Name, phone number, NRC, cooperative assignment, 4-digit PIN |
| **Cooperative Agent** | Name, phone number, NRC, staff ID, cooperative assignment, password |
| **Wholesale Buyer** | Name, phone number, NRC, company name, PACRA number, email, password |
| **Administrator** | Name, phone number, NRC, email, password |

## Managing existing users

From the User Management section, you can:

- **View all users** — a paginated list of every user across all roles
- **Search** — find users by name, phone number, or NRC number
- **Edit user details** — update contact information and role-specific fields
- **Archive accounts** — deactivate a user so they can no longer log in

<Note>
  Archived users cannot log in, but their data is fully retained. Use archiving instead of deletion to preserve the user's transaction and activity history.
</Note>

<Warning>
  Only archive accounts if you are certain the user should no longer have access. Archiving is reversible but requires manual reactivation by an administrator.
</Warning>

## Onboarding additional administrators

The first administrator account is seeded automatically when the platform is set up. All subsequent administrator accounts must be created by an existing admin from the User Management section. Follow the same onboarding steps above and select **Administrator** as the role.
